## Stage graph (LG boss)

```text
START
  → orchestrate          # or-orchestrator plans ledger file
  → research             # or-researcher → notes/<slug>-research.md
  → model                # or-modeler → outputs/<slug>-schema.json (NO objective)
  → gate_schema          # code; fail → model (max K)
  → solve                # tool solve_mock | solve_ortools
  → gate_solution        # code; status OPTIMAL/FEASIBLE + required fields
  → explain              # short notes/<slug>-explain.md from solution only
  → draft_paper          # or-writer → papers/<slug>.md
  → review_pack          # parallel: r1 script, r2 script, or-reviewer
  → revise?              # if fail and revise_count < 2 → draft_paper
                         # if fail and revise_count >= 2 → HUMAN_REQUIRED end
  → provenance           # outputs/<slug>.provenance.md
  → END
```

Pi subagents run **inside** nodes; they do not advance LG edges.
