**Goal:** After T1 CLOSED/PASS, ship a **thick** T2 that hardens **numeric truth** (contracts + real solvers + validate + multi-class fixtures + bounded solve repair) **and** wires the **full knowledge spine** (seed graph + MinerU Cloud + LightRAG + BM25/FTS + RRF + Cognee Cloud) into Researcher/LG, with dual-path CI + live multi-agent evidence, gates, docs, and portfolio talk — without reopening T1 DoD unless `t1_gate` regresses.

- **Knowledge:** MinerU preprocess → unified chunks (`chunk_id`) → LightRAG ∥ BM25/FTS → RRF → Researcher; L3 Cognee Cloud; L4 domain seed graph.

## Contracts (normative)

### Solution (all classes)

```json
{
  "problem_id": "tsp_n8",
  "problem_class": "tsp",
  "status": "OPTIMAL",
  "objective": 123.0,
  "solver": "ortools-routing",
  "source": "tools/solve_ortools.py",
  "path": null,
  "tour": ["0", "3", "1", "…", "0"],
  "routes": null,
  "meta": { "vehicle_count": null }
}
```

- SP: require `path` (node list).  
- TSP: require `tour` (return to start).  
- VRP: require `routes` (list of vehicle routes) + capacity-respecting validate.  
- `status`: `OPTIMAL | FEASIBLE | INFEASIBLE | ERROR`.  
- Forbidden for modeler schema: any key in `{objective, optimal, objective_value, optima, optimal_value, optimal_cost, tour, routes}` **if they encode solution** — allow structural `nodes/edges/matrix` only. Be strict: **no numeric optimum fields** in schema.

### ValidateReport

```json
{
  "ok": true,
  "problem_id": "…",
  "checks": [
    {"name": "envelope", "ok": true},
    {"name": "recompute_objective", "ok": true, "expected": 42, "got": 42},
    {"name": "edge_feasibility", "ok": true},
    {"name": "capacity", "ok": true},
    {"name": "gold_gap", "ok": true, "gap": 0.0}
  ],
  "errors": []
}
```

### Chunk / RetrievalHit

- `chunk_id`, `doc_id`, `text`, `source_path`, `page`?, `mineru_job_id`?  
- Hit: `chunk_id`, `score`, `backend` (`lightrag|bm25|fts|seed|rrf`), `snippet`.
