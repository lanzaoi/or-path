# OR-Path V0→M0 Implementation Plan（LCC 骨架 · specs 为法）

> **For Hermes:** 实现时按 task 切片推进；默认 **只做 V0 再并入 M0 证据**，禁止顺手开记忆/MCP/Teams。  
> **法源优先级：** 门禁真输出 > `specs/product-flow-sdd.md` ≥ `specs/process-visibility.md` ≥ 其它 `specs/**` > AGENTS.md > 本 plan > `docs/harness-ideal-on-lcc-skeleton.md` > LCC 原站。  
> **叙事源：** [Learn Claude Code](https://learn.shareai.run/zh/)（shareAI-lab）+ 本仓 `docs/harness-ideal-on-lcc-skeleton.md`。  
> **本 plan 状态：** 规划 only（2026-08-03）；specs 已冻结 S1，**代码未开工**。

**Goal:** 交付 **V0 Live Watch 硬底线**，再完成 **M0 = V0 + 可信数字 + 真 sub 证据**；用 LCC 的 harness 层次讲清产品，**不**重做 nano Claude Code。

**Architecture:**  
- **全局进度 loop = LangGraph**（翻页 / 回边 / HUMAN / resume）  
- **站内 agent loop = Pi**（lead 无 write → 真 `subagent` → 文件路径回写）  
- **计算器/质检 = 脚本工具**（solve / validate / schema / R*）  
- **脸 = Watch 读盘聚合**（无 LLM 编协作故事）  

**Tech Stack:** 现有 Python/`orpath/*` + stdlib `http.server`（或等价薄 HTTP）+ 静态 `watch.html` 轮询 ≤3s；复用 `detect_subagent_calls`、`runs/<thread>/stages`、`outputs/.agents`。

## 2. 目标架构（V0 数据流）

```text
LG/Pi/脚本 写盘（已有）
    │
    ├─ runs/<thread>/stages/*.json          → L0 (+ 计数器/L4 paths)
    ├─ runs/<thread>/latest_snapshot.json   → 当前站快照
    ├─ outputs/.agents/<slug>/*-lead-*.log  → L1/L2 事件解析
    ├─ outputs/.agents/<slug/*-harness.json → 派工元数据
    ├─ outputs/<slug>-solution.json 等      → L4 链接
    └─ （可选）.pi-subagents/**             → L2/L3 加深
                │
                ▼
     orpath/watch_snapshot.py   # 纯聚合，无 LLM
                │
                ▼
     GET /api/snapshot?slug=&thread=
     GET /api/health
                │
                ▼
     orpath/web/watch.html      # 三栏；setInterval ≤3000ms
                │
                ▼
     scripts/orpath_watch.py    # HTTP + 静态 + 可选 open browser
                │
                ▼
     orpath.bat watch / menu「实时过程台」
```

### Task A2: 实现 L0 扫描（stages）

**Objective:** 从 `runs/<thread_id>/stages/*.json` 聚合成有序 stages + current。

**Files:**
- Create/Modify: `orpath/watch_snapshot.py`
- Test: `scripts/watch_snapshot_gate.py` 或 `tests` 若项目惯用 scripts/*_gate.py（**本仓门禁风格 = scripts/*_gate.py**）

**逻辑要点：**
1. `thread_id` 默认 = `slug`（与 gui-demo / menu-full 惯例一致）；允许 `--thread-id` 覆盖。  
2. 无 `runs/<thread>/stages` → `status=no_product_run`，`stages=[]`，honesty 提示。  
3. 按文件名 `NNNN_` 排序。  
4. `current` 优先 `latest_snapshot.json`，否则最后一条 stage。  
5. `state` 启发式：`human_required`→blocked；`last_error` 非空→fail；末条且无终态可标 running（保守：无 mtime 心跳时可用「末条 + 无 provenance 终态」或仅展示 ok 序列 + latest 高亮）。  
6. **禁止**调用 LLM。

**验收命令（示意）：**

```bash
# 仓库根，使用项目 venv python
python -c "from orpath.watch_snapshot import build_snapshot; import json; print(json.dumps(build_snapshot(slug='test'), indent=2, ensure_ascii=False)[:2000])"
```

Expected: `stages` 非空（若本机已有 `runs/test`）；`schema_version==1`。

### Task A3: 实现 L1 派工树（agents 目录 + detect_subagent_calls）

**Objective:** 扫描 `outputs/.agents/<slug>/`，只认真实 subagent 证据。

**Files:**
- Modify: `orpath/watch_snapshot.py`
- Reuse: `orpath.subagent_dispatch.detect_subagent_calls`（或 `subagent_runtime`）

**逻辑要点：**
1. 收集 `*-lead-*.log`、`*-harness.json`、`*-subagent.json`、`lead-manifest.json`。  
2. 对每个 lead log：读文本（大文件尾部窗口，如最后 256KB）→ `detect_subagent_calls`。  
3. `subagent_detected=false` 且 harness 声称 MA → `cosplay=true`，**dispatches 可不展示为成功 sub**，honesty 记录。  
4. 从文件名/harness 推断 stage/role：`research-lead`→ research/or-researcher；`model-lead`→ model/or-modeler；`cite-`→ verifier；`review-`→ reviewer。  
5. LIVE 探测：可读环境或 harness 字段；`live_off` 时总览条标明。

### Task A4: 实现 L2 事件流 + L3 thinking 诚实态

**Objective:** 从 lead JSON 流解析 tool/assistant/thinking；无则 `thinking_unavailable`。

**Files:**
- Modify: `orpath/watch_snapshot.py`

**逻辑要点：**
1. lead log 多为 JSONL / 混行：逐行 `json.loads` 失败则当纯文本一行 `kind=meta`。  
2. 识别 `toolCall` / `tool_result` / `assistant` / `thinking`|`reasoning`（字段名兼容多供应商）。  
3. 事件列表默认 cap（如 200 条最新）；UI 可再截断。  
4. L3：若全程无 thinking 类 → `thinking.status=thinking_unavailable` + 固定中文/英文说明（与 specs §4.4 一致）。  
5. 可选：若存在 `.pi-subagents/**` 且路径可解析，追加 transcript 事件；找不到不炸，只标 `transcript_missing`（当 `subagent_detected` 时）。

### Task B2: HTTP 服务脚本

**Objective:** `python scripts/orpath_watch.py --slug test` 起服务并可选打开浏览器。

**Files:**
- Create: `scripts/orpath_watch.py`

**行为：**
1. 绑定 `127.0.0.1`（默认端口如 `8765`，占用则 +1 或 `--port`）。  
2. 路由：

4. `--no-browser` 供 CI；默认 Windows `os.startfile` / `webbrowser.open`。  
5. Ctrl+C 干净退出。

**Run:**

```bat
.venv-314\Scripts\python.exe scripts\orpath_watch.py --slug test --no-browser
curl http://127.0.0.1:8765/api/health
curl "http://127.0.0.1:8765/api/snapshot?slug=test"
```
