## 单条题面（文本 / PDF）

```bat

:: CLI only (no graph solve)
orpath.bat intake --slug demo --in path\to\q.txt

:: or tools:
.venv-314\Scripts\python.exe tools\intake_ocr.py --slug demo --in path\to\q.txt --root . --notes-dir notes
.venv-314\Scripts\python.exe tools\intake_parse.py --slug demo --ocr-raw notes\demo-ocr.raw.md --root . --notes-dir notes --outputs-dir outputs
.venv-314\Scripts\python.exe tools\gate_intake.py outputs\demo-intake.json --brief notes\demo-problem-brief.md
```

## 图内 intake（S5，默认 skip）

```bat
:: legacy — skip_intake=true，与 T1/T3 相同
orpath.bat run --problem-id shortest_path --solve-mode mock --slug demo --fresh

:: enable intake front-door then full product graph
orpath.bat run --problem-id shortest_path --solve-mode mock --slug demo-in ^
  --intake-in path\to\q.txt --fresh
```

拓扑：`START → intake_ocr → (intake_parse?) → orchestrate → …`  
无 `--intake-in` 时 `intake_ocr` 立即跳到 `orchestrate`。

## 产物

| 文件 | 说明 |
|------|------|
| `notes/<slug>-ocr.raw.md` | OCR 原文 |
| `notes/<slug>-ocr.meta.json` | backend / sha256 |
| `notes/<slug>-problem-brief.md` | 审题 brief（无最优值） |
| `outputs/<slug>-intake.json` | 结构化 intake |

## 非目标（勿宣称）

- OCR 100% 正确  
- intake 替代 solve  
- 跳过 `skip_intake` 的老 T1 路径被破坏（默认仍可不跑 intake）
