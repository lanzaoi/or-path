# Release v0.3.0 — 说明（待打 zip / 上传）

**相对 v0.2.0：** 技术栈竖切加厚（知识轨、promote、tube LIVE 可绿、claim 诚实），不是新 UI 壳。

## 为何要发 0.3.0

v0.2.0 半肥包 **不包含** 此后 main 上的：

| 能力 | 说明 |
|------|------|
| Knowledge RAG v1–v3 | hybrid · lit 主粮 · research profile · phase5-v3-gate |
| promote-run | 跑完题 → skill/lesson → allowlist → sync |
| Tube 产品路径 | 确定性 schema · envelope · LIVE ma2 可全绿 |
| claim_map / R2 | 否定句诚实；过程计数 `claims_recorded` 不误杀 |
| Specs 瘦身 | `engineering-hygiene`；教程 `docs/user-guide.md` |

路人若只装 v0.2.0 zip，会缺上述命令与修复。  
**开发者** `git pull` main 即可，不必等 zip。

## 版本号

- 文件：`VERSION` → `0.3.0`  
- Tag 建议：`v0.3.0`  
- 资产名：`orpath-0.3.0-win-x64.zip` + `SHA256SUMS` + `install.ps1`
