# Release v1.0.0 正式版 — 发行说明（Release Notes）

**发布里程碑：** OR-Path v1.0.0 官方正式版  
**发布日期：** 2026-11-07  
**核心定位：** 纯 Python 原生驱动的高端工业运筹优化（Operations Research）自动化求解与学术论文生成平台。

---

## 1. 核心重大升级与里程碑成就（What's New in v1.0.0）

### 1.1 彻底剥离 Node.js，全面迈入纯 Python 原生架构
- **零 Node.js / npm 依赖**：永久退役旧版 Node.js `pi` CLI 子进程包装层，系统 100% 运行于标准 Python 虚拟环境中。
- **原生直连主流 LLM**：通过 OpenAI 兼容协议直连科大讯飞星火（`spark-x2.6`）、DeepSeek（`deepseek-chat` / `deepseek-reasoner`）等大模型 API。
- **本地高效 RAG**：集成轻量级 ONNX `bge-m3` 语义向量嵌入与 SQLite FTS5 / BM25 混合检索，无需外部臃肿服务。

### 1.2 精简 4-Agent + 0-Token 确定性门禁 + 10 领域装备包（5×5 主计划 100% 落地）
- **4 大常驻精锐特种兵**：
  - `or_analyst`（题面解构与约束辨析）
  - `or_modeler`（形式化建模与求解脚本生成）
  - `or_writer`（基于预渲染真数据表的六章学术论文撰写）
  - `or_reviewer`（严苛红队审稿与 R1/R2 闭合性核查）
- **0 Token 纯 Python 确定性门禁**：彻底取代大模型 Supervisor 轮询点名，由 LangGraph 状态图条件边执行硬性状态迁移与回修上限（熔断防死循环）。
- **10 Pluggable `DomainCartridge` 装备包**：动态向智能体注入领域专用数据探针（`profile_<domain>_data`）与方案质检工具（`inspect_<domain>_solution`），绝不复制代码膨胀。

### 1.3 27 台重型工业求解器矩阵全谱系（27 Industrial Solvers）
覆盖组合优化与数学规划 7 大主流领域：
1. **路径、流与图论**：NetworkX 最短路、CP-SAT TSP、HiGHS MTZ TSP、OR-Tools CVRP/VRPTW、PyVRP (HGS/PDP)、网络最小费用流。
2. **车间生产与工程调度**：JSSP/FJSSP（PyJobShop CP-SAT，支持换模时延与甘特图输出）、RCPSP（PSPLib CPM + CP-SAT）、员工护士轮班排程。
3. **设施选址与网络设计**：有容量选址 CFLP (HiGHS MIP)、轴辐式枢纽选址 p-Hub (HiGHS MIP)、二次分配 QAP。
4. **空间下料与立体装箱**：三合一全功能装箱（3D py3dbp / 2D rectpack / 1D MIP）、多联骨牌平面精确平铺 (DLX / CP-SAT)、国赛 B 题 3D 异构圆管套裁。
5. **新能源园区与微电网**：光储充一体化微电网调度（分时电价套利、需量削峰、电池寿命衰减非线性折损、滚动时域 MPC）。
6. **批量库存、金融与随机**：Wagner-Whitin DP、CLSP 有能力批量规划、马科维茨风险平价投资组合、两阶段随机线性规划。
7. **离散图论与博弈论**：最大团补图对偶判定、DIMACS 顶点着色、伊辛模型/QUBO 模拟退火、双矩阵纳什均衡 (Nashpy)。

### 1.4 Numbers Truth 独立物理校验与 DIMO 5 类变异防御
- **数字真理铁律**：所有最优值与决策序列 100% 经物理求解器真实运算与校验器独立复算，大模型绝无权编造数值。
- **DIMO 5 类对抗性变异检验**：目标篡改、约束破坏、维度伪造、状态翻转、微小浮点扰动 100% 拦截率（`universal_redteam_gate.py` 全过）。
- **严格宣称阶梯**：未证明最优解一律报告真实下界与 Optimality Gap，严禁伪造“全局最优”。

### 1.5 Web Studio 智能做题工作舱与全透明实时过程看板
- **一键启动**：`START.bat`（Windows / WSL）或 `./START.sh`（Linux / macOS）一键启动双向工作舱。
- **拖拽做题与数据画像**：支持文件夹/文件拖拽题目摄入，`studio_analyzer.py` 自动分析数据表维度并提供反问研判。
- **人机协同确认弹窗**：支持在求解前交互式调整算法模式、时间上限与断点设置。
- **Live Watch 实时看板**：全要素透明展示 L0（阶段流转）、L1（单兵时序）、L2（工具明细）、L3（思维链）与 L4（物理产物）。

## 3. 一键安装命令

### Windows (PowerShell)
```powershell
irm https://github.com/lanzaoi/or-path/releases/download/v1.0.0/install.ps1 | iex
```

### 源码一键 Clone
```bash
git clone https://github.com/lanzaoi/or-path.git
cd or-path
.venv/bin/pip install -r requirements.txt
./START.sh  # 或 START.bat
```
