# Release v1.1.0 — 发行说明（Release Notes）

**发布里程碑：** OR-Path v1.1.0 稳定加固版  
**发布日期：** 2026-11-07  
**核心定位：** 纯 Python 原生驱动的高端工业运筹优化（Operations Research）自动化求解与学术论文生成平台。

---

## 1. 核心升级与加固（What's New in v1.1.0）

### 1.1 Web Studio 数据集智能探针与端到端工作台贯通
- **Excel 赛题附件自动识别**：在 `orpath/studio_analyzer.py` 中扩充了对现代数模竞赛（如国赛、美赛）常见 `.xlsx` 数据附件（如 `result*.xlsx`、`附件*.xlsx`）的自动探针识别，支持工作台零配置拖拽导入。
- **全链路竞赛真实场景实测打通**：以 CUMCM 2026 C 题“园区微电网光储充协同调度”为真实基准，验证了从题面拖拽摄入、数据画像、人机交互确认、底层 HiGHS MIP 求解器 28.52 秒高效规划、26 项物理守恒指标 100% 独立验证到 Live Watch 毫秒级看板呈现的全链路闭环。

### 1.2 系统安全加固与网络防御
- **路径穿越（Path Traversal）安全拦截**：`scripts/orpath_watch.py` 在处理所有 GET 请求（`/api/artifact`、`/api/poll`、`/api/snapshot`、`/api/stream`、`/api/steer` 等）时，严格对 `slug` 和 `thread` 执行 `_sanitize_slug` 白名单字符清洗（限制为 `[A-Za-z0-9_-]`），彻底杜绝目录遍历漏洞。
- **默认监听地址安全加固**：启动脚本 `START.sh` 及 `orpath.sh` 默认监听地址由宽泛的 `0.0.0.0` 调整为安全本地回环 `127.0.0.1`（支持通过 `ORPATH_HOST` 环境变量自定义），避免端口未经授权暴露于外部局域网。
- **数据库连接泄漏防御**：重构 `orpath/run_orpath.py` 与 `scripts/orpath_watch.py` 中的 SQLite Checkpointer 句柄生命周期管理，统一使用 `try ... finally: conn.close()`，彻底杜绝数据库句柄未释放造成的崩溃或死锁。

### 1.3 管道鲁棒性防空护栏
- **空解与路径容错**：在 `orpath/pipeline/solve.py` 中增加对解文件路径的空串与非文件类型防护，防止在求解未生成解时触发 `IsADirectoryError`；在 `orpath/pipeline/paper.py`（`node_revise_or_done` 与 `node_cite_pack`）中增强了针对空 `solution_path` 的安全降级防护。
- **语法与逻辑补正**：修复了 `orpath/agents/adaptive_graph.py` 中的语法括号闭合缺陷。

### 1.4 Numbers Truth 运筹底线与数字真理
- **启发式算法最优性宣称审查**：在 QUBO/Ising 退火、复杂装箱、离散投资组合等求解器中严格遵循 Numbers Truth 铁律：未证明全局最优时一律标注启发式解状态，严禁在 LLM 报告或求解元数据中伪造“全局最优”。

### 1.5 代码库工程卫生（Engineering Hygiene）
- **废弃垫片下线**：彻底移除已弃用的旧版过渡模块 `orpath/graph.py` 与 `orpath/graph_t2.py`，统一收敛至稳定控制面 `orpath/graph_product.py`。
- **测试归位与整洁**：将遗留在业务目录中的 `test_process_memory.py` 迁移至标准测试目录 `tools/`。
- **无死引用规范**：清理了 `orpath/gates.py`、`tools/validate_solution.py` 等 11 个核心模块中的死引用与冗余导入，清除工作区临时备份。
