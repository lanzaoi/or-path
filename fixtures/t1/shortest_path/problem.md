# 最短路 / Shortest Path (T1 fixture)

## 中文

给定有向加权图，节点为 `S`、`A`、`T`。边权：

- `S → A`：10
- `A → T`：32
- `S → T`：100

求从起点 **S** 到终点 **T** 的最短路径及其总代价。

## English

Given a directed weighted graph with nodes `S`, `A`, `T` and edges:

- `S → A` weight 10
- `A → T` weight 32
- `S → T` weight 100

Find the **shortest path from S to T** and its total cost.
